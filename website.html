🔧 Chrome Extension Remover

Easily manage and remove Chrome extensions

ℹ️ About This Tool

This tool helps you view and remove Chrome extensions. Since web pages cannot directly uninstall extensions for security reasons, this page provides you with multiple methods to remove extensions from your browser.

📋 Methods to Remove Extensions

Method 1: Chrome Settings (Recommended)

  1. Open Chrome and go to chrome://extensions
  2. Find the extension you want to remove
  3. Click the Remove button
  4. Confirm the removal when prompted

Method 2: Quick Links Below

  1. Use the button below to open Chrome Extensions page
  2. View the list of installed extensions
  3. Find and remove extensions using the interface

Method 3: Using Command Line (Advanced)

  1. On Windows: Open PowerShell and run:
    Remove-Item -Path "$env:LOCALAPPDATA\Google\Chrome\User Data\Default\Extensions\*" -Recurse -Force
  2. On Mac: Open Terminal and run:
    rm -rf ~/Library/Application\ Support/Google/Chrome/Default/Extensions/*
  3. On Linux: Open Terminal and run:
    rm -rf ~/.config/google-chrome/Default/Extensions/*
  4. Close Chrome completely before running these commands
  5. After running, restart Chrome
